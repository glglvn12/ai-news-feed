# index.html — AI News Feed (main page)

Scope: the only page. Mode: Operate (a quick daily scan by one owner on their Mac).
Task: see in seconds what's new, major labs first; search/filter when needed; refresh live.
Constraints: follow system light/dark; major labs (OpenAI, Anthropic, Google DeepMind, TypeSafe/Jev, Nous Research/Hermes) stand out; no lab logos; keep help section, Refresh, search, source and category filters.

## Direction contract

THESIS: The feed is a news-agency wire. Every item carries a priority code; major-lab releases arrive as MAJOR LAB items that sit above routine copy. Refuses the category default of a flat list of equal cards with coloured chips.

OWN-WORLD: Ink-black wire header band across the top; cool grey-white copy ground (light) / carbon ground (dark); one bulletin red reserved for major-lab priority, an ochre for other labs, ink for papers and press. Archivo semi-condensed headlines, JetBrains Mono only for times, codes and counts (data). Rows ruled by 1px rules, no cards.

STORY: Open the page, read the red MAJOR LAB lane, see what is new since the last visit, skim today's wire, filter only if hunting.

FIRST VIEWPORT: Header band: wordmark left, wire status centre (updated time, new count, failed sources), Refresh right. Control row: search, category tabs (All / Labs / Research / Press), source select. Then the Bulletins lane: latest major-lab items in red-coded rows. Then the dated wire: time | code | source | headline + excerpt.

FORM: Wire Desk (pick card, ranked 1 of 7 on my list); seed key a20500e2.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
